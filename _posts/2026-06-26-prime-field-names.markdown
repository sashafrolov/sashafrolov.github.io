# TL;DR
We have nice themed names for 32-bit and 64-bit FFT-friendly prime fields (Goldilocks, KoalaBear and Baby). But what about 128-bit prime fields?! These have come up in my work, so I am proposing names for them now.

# PolarBear

I am proposing the name PolarBear for this field. It is used in Meta's winterfell library. Also, 128-bit fields are quite large, so PolarBear feels reasonable.

# SunBear

This field is use din the Google Longfellow library, and the Sun Bear is a "long fellow"

# SquareBear

As proposed by my colleague Kai, we can call both of these the SquareBear fields because they come from approximately squaring a 64-bit prime (or squaring a ~32 bit prime twice).
